# C20 — Visual pipeline foundations
Status: done      Depends on: C11 (does not touch C12–C19)
## Goal
Stand up the CC0 environment-asset pipeline and the chibi-character direction, so C21–C25 can rebuild render quality without re-deriving tooling. Visual-rebuild track (not gameplay).
## Done when
Sample CC0 glTF prop loads, instances in a throwaway scene, renders correctly; `size:check` passes with the new per-biome budget; `pnpm verify` green.
## Shipped
- ADR-0008 (chibi proportions, baked-face toon characters) and ADR-0009 (CC0 environment pipeline) in `docs/decisions/`.
- `apps/game/src/render/assets.ts`: `GLTFLoader` + meshopt decoder (both already bundled in the installed `three` package, no new dependency), `loadAsset`/`preloadBiome` cache keyed by biome, `buildInstancedProp` (one `InstancedMesh` per sub-mesh, driven as a rigid unit across N placements — keeps draw calls at "one per sub-mesh" regardless of instance count).
- Lagos biome-kit: 19 CC0 models (8 low-detail buildings, 4 market props — awning/overhang/parasol×2, 3 palm trees, 2 grass patches, 2 stone-path pieces) from Kenney "City Kit (Commercial) 2.1" and "Nature Kit 2.1" (CC0), under `apps/game/public/models/lagos/`. Raw 284 KB, **63.2 KB gzip** — far under the 1.5 MB/biome budget. `apps/game/public/models/CREDITS.md` names the source packs.
- `tools/size-check.mjs`: new `dist/models/<biome>` budget check (≤1.5 MB gzip), `models/` excluded from the first-load count (same treatment as `states/`). First load unaffected: still 296 KB gzip.
- `apps/game/debug-assets.html` + `src/debug-assets.ts`: dev-only pipeline sanity page (not built into `dist`, not in `vite.config.ts` `rollupOptions.input`) — loads the Lagos kit and renders every asset in a grid. Verified visually via `pnpm --filter @cr/game dev` → `/debug-assets.html`.
