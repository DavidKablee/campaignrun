# C93 — Typed chat (built, switched off)

Presets carry the conversation today. Saying your own words is what turns a room into a community, and it is also where a politics-themed game is most exposed (real names, election claims, abuse, scams). So it is built, tested and shipped **dark**: with `CR_CHAT_ENABLED` unset, nothing in the game changes.

## Who may type (when the switch is on)
- The account is at least 24 hours old (`users.created_at`), 18+ was confirmed at sign-up, and at least one Campaign Job is finished. Everyone else keeps presets and sees one line saying what unlocks it (English and Pidgin, from `places.json` `chat.locks`).
- Every number is in `places.json` `chat` (age, jobs, 80 characters, 4-second gap, reports needed, retention, strikes) and checked by a content test.

## Rules for a message (`api/src/placeChat.ts`, pure and tested)
Empty, longer than 80 characters, a link or handle (`http`, `www`, bare domains on common endings, `t.me`, `@`, "dot com"), seven or more digits however spaced or six number words in a row, a flood (five of one character, a word repeated, almost no variety), the same message twice, or a hashed blocked term (single word, pair or triple, or letters spaced out). A refusal returns a friendly reason to the sender only; it is not stored and nobody else sees it. The filter strips edge punctuation first because the shared normaliser reads a trailing `!` as the letter i.

## Safety loop
- **Mute** is per person and kept on the device by board name (C90).
- **Report** is the existing closed list of reasons. Reports from **three different people** within 24 hours hide that player's text from others for 24 hours. The same person reporting twice counts once.
- **Strikes**: five refused attempts (link, number, flood or blocked word) in ten minutes start a 30-minute cool-down.
- **Shadow**: while hidden, the sender still sees their own text and is not told; others receive nothing.
- **Kill switch**: `CR_CHAT_ENABLED` is read on every request. Anything but `true` returns "off", the box disappears on the next Say tray open, and presets work as before.
- **Review tool**: `pnpm --filter @cr/api report chat` lists players reported in the last 48 hours with the number of different reporters, reasons, whether they are hidden, and their last ten messages; `chat release <name>` lifts a hide, `chat hide <name> [hours]` applies one.

## Privacy
A message is relayed live and a copy is kept in `place_chat` for 24 hours only so a report can be reviewed; the API deletes older rows every ten minutes, and rows go with the account. The privacy text in `legal.json` says this (a test ties its "24 hours" to the setting). `legal.version` was not bumped: the lawyer review of the full notice is still owed, and a bump would re-ask existing players.

## Launch gate (do not turn on before all of these)
1. A lawyer reviews the Cybercrimes Act and data-protection exposure of players' typed text, and the privacy and terms copy.
2. Someone is named to run `report chat` daily and to lift wrong hides.
3. `private/chat-terms.plain.txt` is written (abuse, slurs, scam phrases, English and Pidgin) and hashed in with `node tools/hash-blocklist.mjs private/chat-terms.plain.txt packages/content/data/chat-terms.hashes.json`. `chat-terms.hashes.json` ships empty, so only real-name hashes filter today.
4. The filter is tried by native English and Pidgin speakers, including spelling tricks and election claims. A word filter cannot judge a claim like "the vote was rigged"; that is what reports and the review tool are for.
5. Start with one state or a short window, watch the report rate, and keep the switch to hand.

## Tests
`api/test/placeChat.test.ts`: every rule; age and job gates; off by default; relay to the room; refusal stored and shown to no one; the 4-second gap; typed text counts for the say job; strike cool-down shadows the sender; three different reporters hide a player and one reporter twice does not; 24-hour retention; presets still work; messages go with the account. `packages/content/test/places.test.ts`: settings and privacy copy. Client e2e is unchanged because the box is absent while the switch is off.

## Not done
- The client box has no automated browser test with the switch on (the e2e API runs with chat off).
- Cool-downs and strikes are per API process (in memory), like presence.
- Bubbles show typed text for six seconds; there is no scrollback.
