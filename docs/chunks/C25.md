# C25 — Cross-cutting QA and performance hardening
Status: done (within this environment's limits — see Open)      Depends on: C20–C24
## Goal
Close out the visual & feel rebuild track: regression-check the rest of the app still works, make sure the new CC0 assets behave correctly offline, do a final budget audit, and leave the docs in a state where a phone pass is a checklist, not an investigation.
## Done when
`pnpm verify` green; `docs/PLAYTEST.md` visual-rebuild checklist written; budgets documented and enforced in CI.
## Shipped
- **PWA/offline fix for the new assets**: `vite.config.ts` Workbox config excluded `.glb`/model assets from the precache `globPatterns` (ADR-0009: never part of first load) but — before this chunk — nothing covered them for runtime caching either, and the colormap texture (`.png`, which *does* match the precache glob) was leaking into the initial service-worker install by accident since `models/` wasn't in `globIgnores`. Fixed: `models/**` added to `globIgnores`, and a new `CacheFirst` `runtimeCaching` rule (`cr-biome-models`) mirrors the existing `cr-state-packs` one — assets are cached the first time a run fetches them (e.g. first visit to `park`), available offline after that.
- **Regression check**: confirmed via the Live Board that only Lagos is actually unlocked right now (everything else shows "Pending" with its calendar date) — so there's no live regression surface on Kano/Rivers/Anambra/Kaduna to test yet; they're inaccessible to players until their unlock date regardless of this track's changes. Worth re-checking once more states unlock and the CC0-biome-kit pattern extends past Lagos.
- `docs/ARCHITECTURE.md`: added a "Visual & feel rebuild track" pointer section, documented the `clone()` vs `buildInstancedProp` placement pattern, and the Workbox model-caching rule.
- `docs/PLAYTEST.md`: added a "Visual & feel rebuild QA" checklist (6 items) specifically for what C20–C24 changed, to run on a real phone.
- Final budget re-check (after the Workbox fix): first-load gzip 325 KB (4 MB budget), Lagos biome kit 63.2 KB gzip (1.5 MB budget), all state packs ≤ 0.5 KB. `pnpm verify` green end to end.
## Open (explicitly deferred, not silently dropped — see also C23's Open list)
- **No real phone or throttled-CPU device pass happened in this session.** Everything was verified via the Claude Preview browser tool (desktop + mobile-viewport emulation), which is a reasonable proxy for layout/correctness but its `requestAnimationFrame` throttling makes fps numbers from it meaningless — draw-call/triangle counts were used as the performance signal instead (see C23). This is the single biggest remaining risk in the track: run the `docs/PLAYTEST.md` visual-rebuild checklist on an actual low-end Android before calling this launch-ready.
- No Lighthouse PWA run (needs an HTTPS deploy, not available in this environment) — same blocker noted in `docs/STATUS.md` since before this track started.
- CC0 buildings, sidewalk/curb decals, and LOD on far chunk slots remain open from C23.
