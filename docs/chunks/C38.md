# C38 — Lagos Life UI chrome
Status: done      Depends on: C35–C37
## Goal
Move the interface to the reference's visual language (lagoslife.app) without touching the 3D.
## Done when
`pnpm verify` green; splash, roster, map and auth all read as one app; the worlds are unchanged.
## Shipped
An override block at the end of `apps/game/src/ui/styles.css`, kept as a layer rather than edited
in place so the chrome can be tuned or lifted without disturbing the per-screen layout above it.

- Fully rounded pills everywhere a player taps. Primary actions are a solid forest green with white
  text; secondary actions are a white pill with dark ink — the reference's `Sign up free` / `Log in`
  pairing.
- Soft layered shadows (`ring + lift`) instead of the old hard drop-bar on buttons.
- Floating white cards for `.cr-panel`, `.cr-board-focus` and `.cr-studio-panel`, with the headings,
  figures and fineprint inside them re-inked, because the dark-screen yellow is unreadable on white.
- Form controls: white, 14px radius, green focus ring.
- Body font for UI; the display face stays for big headings only.

The 3D worlds, the run, the studio and the portraits are untouched — the player's choice was chrome
only.
## Open
- **Not every screen has been looked at.** Splash, roster, map and auth were checked at 1280×900;
  briefing, summary, settings, account and the run HUD have not been reviewed since the change.
- The reference is daylight — bright green land, teal water — and Campaign Run's worlds are still
  night. The two sit together better than expected, but a full art pass would change the worlds too.
- No presence counters ("29k online"). The map shows real player counts per region, which is the
  honest version of the same idea, but there is no global one.
