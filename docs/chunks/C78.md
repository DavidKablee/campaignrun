# C78 — Launch plumbing: previews, first minute, challenge loop, Pidgin, corrections, remote calendar

Answers items 2–6 and 8 of the platform critique. Items 1 (hosting), 7 and 9 were not asked for.

## What was built

### Link previews, manifest, anonymous funnel (item 2)
- `apps/game/index.html`: description and Open Graph / Twitter tags; `apps/game/public/og-image.png` (1200×630) generated by `tools/og-image.mjs` from `tools/og-image.html`. `VITE_PUBLIC_URL` makes the image URL absolute at build time (a `transformIndexHtml` plugin in `vite.config.ts`).
- Manifest name and short name are now "Campaigner".
- Analytics (`apps/game/src/analytics.ts`, `packages/content/data/analytics.json`, API `POST /api/events`, table `event_counts`): a closed list of event names, counters by (day, name, state). No identifiers, no cookies, no IP stored. Do Not Track and a Settings switch turn it off. Rate-limited per IP in process memory. `pnpm --filter @cr/api report` prints the funnel and the newest corrections.
- `legal.json` privacy text updated, `legal.version` 2026-10-28 (players are asked to re-accept).

### First minute (item 3, code side only)
- `apps/game/src/coach.ts`: first three runs get coaching; the approach to the first pickup (70 m) triggers a brake prompt instead of waiting for the player to find it.
- New tutorial card (`cr-coach-card`) with a lane flick and a hop demo, reduced-motion safe; darker splash scrim and toast plate so text reads in sunlight.
- **The playtest itself has not been run.** `docs/PLAYTEST-FIRST-MINUTE.md` is the protocol for it.

### Challenge a friend and the tally (item 4)
- The Challenge sheet is now the first thing after the result card, with one-tap WhatsApp (`whatsappUrl`), copy and share. Text is built by `challengeText(…, lang)`.
- `GET /api/tally`: finished-rally counts per state, hidden until 100 in total, counts only, no percentages (`BusiestRoads.tsx` on the campaign map). Needs the API.

### Pidgin (item 5)
- `apps/game/src/i18n.ts` (en / pcm, stored as `cr-lang`), `radioPidgin.ts` radio pools, Settings → "Language and privacy". Only run-time strings are translated (toasts, prompts, tutorial, challenge text, radio).
- **No native speaker has reviewed any of it.** `docs/research/pidgin-review.md` lists every line for a reviewer to mark.

### "Is this your state? Correct it" (item 6)
- `StateCorrection.tsx` on the summary and the campaign map: topic list from `feedback.json`, free text, anonymous. A pattern that looks like a phone number, email or link is refused on the client and the server. `POST /api/feedback/state` stores to `state_feedback` for the reviewer list.

### Remote calendar and archive mode (item 8)
- `campaignClock.ts` reads `flags.json` (`calendar.closeAt`, `calendar.unlocks`, `notice`). Dates outside 2026-10-01…2028-01-01, malformed dates and unknown states are ignored. After the close every state with a pack opens for practice and the pill reads "Closed".
- `flags.json` was precached by the service worker, so the kill switch and these dates would not have reached returning players. Fixed: it is out of the precache and served NetworkFirst with a 3 s timeout.
