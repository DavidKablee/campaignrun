# C39 — About, Settings, Account and the Convoy Yard
Status: done      Depends on: C37 (accounts/API), C38 (Lagos Life chrome)
## Goal
C38 moved the chrome to the reference's language on the screens that were reviewed — splash,
roster, map, auth. The four pages you *read* rather than play were not among them and were still
in the pre-C38 idiom. Redesign them as one family.
## Done when
All four render in the C38 language, every one of them scrolls on a 390×844 phone, and the Account
page can answer "am I signed in?".

## Shipped
### One shell for four pages
`ui/MenuChrome.tsx` holds what they share: `MenuHead` (a round back button in a fixed place, a
left-aligned title, an optional one-line subtitle), `Sheet` (a white floating card, optionally
`flush` so its rows own the padding and the dividers reach the edges), `Row` and `Toggle`.
Each screen stacks its own sheets — the Yard's shop sections and the About page's prose want very
different internal rhythm, so the shell deliberately does not own layout.

The four screens left `App.tsx` for `ui/`, which is where `CampaignMap` and `AuthScreen` already
lived: `AboutScreen.tsx`, `SettingsScreen.tsx`, `AccountScreen.tsx`, `ConvoyYard.tsx`, plus
`DailyChip.tsx` (shared by the Yard, the briefing and the summary, so it could not stay in
`App.tsx` without the Yard importing its own parent). `App.tsx` drops from 1560 to 1217 lines.

### What was actually wrong, not just old
- **None of these screens could scroll.** `.cr-screen--settings` centred its children with
  `justify-content: center` and no `overflow`, so About, Settings and Account measured
  `scrollHeight === clientHeight` at 390×844: the content had been quietly squeezed to fit and had
  nowhere to go. The three now measure 1190, 844 and 1329 against an 844 viewport and scroll.
- **Prose was centred.** Fine for three words, poor for a privacy notice. Everything reads
  left-aligned now.
- **Cream `.cr-card` with a hard `0 8px 0` drop-bar** next to C38's green pills and white floating
  surfaces. Replaced by `.cr-sheet`.
- **The local-name field was invisible.** `.cr-board-submit label` is cream (`rgba(247,241,227,.7)`)
  because it was written for a dark panel; inside Account's cream card the label was cream on cream
  and the input was a dark grey slab. It is a `.cr-field` now, which C38 already styles for light.
- **Yard progress bars sat in a three-column grid**, so on desktop every bar was a short stub
  floating against the right edge, far from its label. Each goal is now a label row with the bar
  full-width underneath.
- **Locked upgrades and rides were `disabled` and ghosted**, which reads as broken rather than as
  locked. An upgrade you cannot afford states its price on a greyed button; a locked ride says how
  much Following is still missing. Both also show `description`/`trait`, which the content has
  carried since C08 and nothing had ever displayed.
- **Switches.** `Toggle` draws a real `<input type="checkbox">` as a track and knob via
  `appearance: none` — still focusable, still a checkbox to the accessibility tree, no ARIA needed.

### Account tells the truth now
It still read **"Cloud sign-in comes later"** two chunks after C37 shipped sign-in, and there was
no way to tell from this screen whether you were signed in. The identity sheet at the top now
shows the account name and email with a `Signed in` / `This device` / `Offline` chip, a sign-out
button, and — when signed out — the route to `auth`.

`deleteOnlineAccount()` existed in `onlineStore.ts` since C37 and had no caller: there was no way
to delete a server account from inside the game. It is wired to a "Delete your account" row that
only appears when signed in.

**The Contender switch now writes to both sides.** It only ever touched the device consent log,
so a player who withdrew consent while signed in left their Contender ids sitting on the server.
`shareConsentPlan(next, signedIn)` in `consent.ts` is the decision, extracted so it is testable:
the local log is always written, and the server is told only when there is an account — including
on withdrawal, because that call is what erases ids already stored. Verified end to end against
the local database: `/api/auth/me` reported `shareContender` false → true → false as the switch
moved.

### Legal copy, and a version bump
Two strings had gone stale and one was incomplete:
- `guestSaveBody` ended "Cloud sign-in arrives later."
- `contenderConsentBody` described the server in the future tense.
- `privacyBody` said progress is stored on the device and did not mention that an account stores an
  email, a board name and scores on a server.

All three are rewritten, and `legal.version` moves `2026-10-08` → `2026-10-21`. The bump is the
point: the meaning changed, so prior acceptance should not carry over. Everyone re-accepts, which
is the behaviour already built — `termsAcceptedVersion !== legal.version` gates `saveLocalAccount`.

### The 200-player floor has one home
The About page explains why a state can show practice numbers, which meant quoting the privacy
floor — and AGENTS.md says tunable numbers live in content, not inline. `minPlayersPerRegion: 200`
joins `map.json` → `standings`; the About copy interpolates it and `MIN_PLAYERS_PER_REGION` in the
API now falls back to it instead of its own literal `200`. `CR_MIN_PLAYERS` still overrides, which
is all it was ever for (lowering the floor for a local demo). A second copy of that number is a
promise to the player that can drift from what the server enforces.

### Dead CSS removed
`.cr-yard-block`, `.cr-mission-list`, `.cr-settings-card` and `.cr-settings label` have no callers
left and are gone.

## Tests (174 with a database, was 170)
- `C39: the Contender switch and the server` (3) — the local log is always written; the server is
  never called for a signed-out player; **the server is told on withdrawal, not only on consent**,
  which is the case that leaves data behind if it regresses.
- `C39: the privacy floor has one home` — `campaignMap.standings.minPlayersPerRegion` is 200.

## Open
- **Verified at 390×844 and 1280×800 in a desktop browser, not on a phone.** Same gap every chunk
  since C20 has — the switches and the 44px back button are sized for thumbs but have never met one.
- **Summary, briefing, paused and the run HUD are still pre-C38.** The four menu screens, splash,
  roster, map and auth are now in the new language; those four are not.
- The Yard's upgrade rows disable the buy button on affordability, so with ₦0 the whole shop is
  grey. Readable, but a "keep running to afford this" line would be kinder than five grey pills.
- `legal.version` moved, so anyone who had accepted will be asked again. That is intended; it is
  also the first time this has happened, so the re-acceptance path has only been exercised by me.
