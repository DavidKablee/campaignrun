# C85 — One word per idea

## What changed
- **Crowd** is the run score, everywhere (glass, result, share card, challenge text in English and Pidgin, radio). "Turnout" is gone.
- **Supporters** are the people on the bus (the HUD says "Aboard").
- **Following** is the ride-unlock and Mobilise currency. Code keeps the name `following`.
- Result tiers read **Small / Packed / Overflowing**. The ids `foothold`, `majority`, `landslide` and saved data are unchanged, so replays are not affected.
- The Board says "ahead by" (later "in front here", C86), not "leads by".
