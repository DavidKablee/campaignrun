# C28 — Rival convoys + remaining 5 Integrity events
Status: done      Depends on: C06 (integrity), C26 (ride roster)
## Goal
Close two more spec items that were never built: the 5 remaining Integrity events (spec only shipped Snatcher/Vote-Buyer/Sleepy-Voter in C06 — Result Swapper, Network Glitch, Late Materials, Spot the Fake, PVC pickup were never implemented), and Rival Convoys (spec §4.6, not started at all). Both are genuinely client-side-only — no backend needed — so they belong in this track rather than waiting on C12+.
## Done when
`pnpm verify` green; equal-frequency tests pass for both the extended Integrity round-robin (3 kinds → 7) and the new rival-convoy round-robin (4 ride models); none of the new mechanics can end a run or touch Crowd/map-relevant scoring in a way that breaks balance.
## Shipped
- **4 new negative Integrity events** (Result Swapper, Network Glitch, Late Materials, Spot the Fake) extend the exact C06 pattern: round-robin spawn (`integritySpawnSeq % kinds.length`, now 7 kinds instead of 3 — equal frequency is structural, not approximate), hit = integrity loss + a kind-specific effect (speed delay for Swapper/Glitch/Late-Materials, small crowd nibble for Spot-the-Fake), dodge = `integritySuccess` + integrity gain, exactly like the existing 3. `packages/sim/src/step.ts`, `packages/sim/src/course.ts`.
- **PVC pickup** implemented as what the spec actually describes — a **positive** collectible, not a hazard. New `SimState.pvcBuffTicks` field; picking one up grants a ×1.1 Crowd multiplier for 10s (`config.bonuses.pvcMultiplierPermille`/`pvcDurationTicks`, tunable in `sim.json`) applied in `deliverCrowd`. Zero integrity cost, zero carried cost — verified by a dedicated test.
- **Rival convoys** (spec §4.6), scoped to the always-on core of the mechanic rather than all 4 sub-interactions:
  - NPC entities (`isRivalConvoy: true`) spawn round-robin through 4 ride models for visual variety.
  - **Touch = small bump**: `config.bonuses.rivalBumpSpeedPermille` (850‰, much gentler than a real hit's 450‰) — never a dent, never an integrity hit, never ends a run. Matches spec's explicit "touch = small bump, lose speed only."
  - **Draft & Overtake → Outpace bonus**: passing a rival without touching it grants a flat `config.bonuses.rivalOutpaceCrowd` (6) skillCrowd bonus on despawn, same mechanism as the existing `integritySuccess` cleanup-on-despawn pattern.
  - **Deferred, not built**: Contest a Venue, Face-off (5-tap sequence), and Peace Salute all need bespoke timing/input UI (chant bars, tap sequences) that would roughly double this chunk's scope for 3 situational sub-mechanics vs. the one that's always-on. Logged in Open below, not silently dropped.
- **Rendering**, so none of this ships invisible (same gap I caught and fixed for rides in C26): `buildPvcCard` (glowing collectible card, visually distinct from the hazard cast), 4 new `integrityGeo` villain variants reusing the exact existing style (generic masked figures, neutral colours, small kind-specific prop — never party colours, per the spec's own villain guardrail), and rival convoys reuse the C26 ride models (`buildOkada`/`buildKeke`/`buildHilux`/`buildDanfo`) at a slightly larger scale so they read as "another convoy" rather than the player's own ride.
- New/extended tests: `packages/sim/test/integrity.test.ts` now covers all 7 round-robin kinds, each new kind's distinct fail behaviour, PVC's positive-only effect, rival bump/outpace/round-robin. 86 tests total (was 81 after C27).
