# C54 — Kaduna's world

## Why
Kaduna rendered the Kano-style Sahel world in a different tint. See ADR-0010, C50–C53. The dossier is `docs/research/states/kaduna.md`; I read it in full and kept its reviewer flags.

## What
- **Landmarks** (`data/states/kaduna.json`, all `verified: false`): Bakin Dogo Market (market), Kaduna Township Stadium (stadium), River Kaduna Rail Bridge (bridge), Splash Park (park), Matsirga Waterfalls (waterfront). The pack's "Kawo Market" (demolished), "Centenary Park", "Rigasa Square" and "Central Stadium Ground" were not found or were rejected in the dossier. Palette from the dossier (sky `#AFC4D4`, fog `#E4E8E4`, ground `#9B6A4C`); accent changed from the party-red `#C0392B` to burnt clay `#B9663A`. Welcome and farewell kept ("Barka da zuwa Kaduna!", "Na gode, Kaduna!").
- **Route:** GRA avenue start (hipped terracotta bungalows under big neem and mango) → Tudun Wada produce lanes → stadium roundabout → River Kaduna crossing (level crossing, truss bridge, river on the left) → Riverside park → falls and hills road (granite boulders, maize) → hill village (zinc houses, a few thatch-gable huts) → Kakuri works road (long blank mill walls, tea kiosks) → city-centre avenue (plaza blocks, median). Library `data/world/guinea-savanna.json`.
- **Look:** `redbrown-avenue` road (cleaner dark asphalt, red-brown laterite shoulders), `limewash` facades (cream, whitewash, sandcrete, ochre, slate shutters, iron grilles), `hausa-city` shop boards (English trade words and "Kasuwa"), `hausa-guinea` dress (kaftan, tee, Ankara shirt, one riga in seven, kube/turban sparingly, no red caps), granite `inselberg-ridge` skyline.
- **New styles:** lots `tiled-villa`, `plaza-block`, `thatch-hut`, `works-shed`; wall kind `mill`; flora `boulder`; crop `maize`; kerbside `teastall`, `produce`.
- **Set pieces** (`render/world/states/kaduna.ts`): `kaduna.bakin-dogo`, `kaduna.stadium` (with the ball-on-cup roundabout monument), `kaduna.level-crossing` (+ `kaduna.crossing-clear`), `kaduna.rail-bridge`, `kaduna.splash-park`, `kaduna.matsirga-falls`.
- **Anambra review fixes:** ribbed container ends, bigger toll booths, lighter river bank colour. The red lattice frame near the bridge is the district gantry (shared, accent-red), not a bug.

## Not done

- Roof material and colours of colonial bungalows, the rail bridge's paint, keke colours, and the stadium and falls shapes are inferred.
- Kajuru Castle, Kagoro Hills and Rigasa station are not shown (insecurity link, sensitivity, attack).
- No hazard visuals (dust plume, go-slow, cart-weave); no flyover pier at the finish; no real-phone test.

## Also fixed in this chunk: a selected state drew the Lagos world in long-running dev servers
- **Symptom:** picking an open state in the app still showed the Lagos world.
- **Cause:** `import.meta.glob` of `packages/content/data/world/*.json` is resolved by Vite when the dev server starts. The content package sits outside the app root, so a server started before a library file was added never saw it, the lazy import failed, and `useStateWorld` silently fell back to Lagos. Production builds were never affected.
- **Fix:** `apps/game/vite.config.ts` has a `cr-watch-content-data` plugin that adds `packages/content/data` to the dev watcher, and `useStateWorld` now logs `console.error` naming the library and state when it falls back. The `cr-state-packs` cache holds 80 entries (was 8). Verified on the 5173 and 5180 dev servers.
- **If it recurs:** restart the dev server, then look in the browser console for "failed to load; drawing the Lagos world".
