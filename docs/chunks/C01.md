# C01 — Sim core
Status: in-progress      Depends on: C00

## Goal
Implement a pure deterministic 60 Hz fixed-timestep integer simulation.

## Build
- `sfc32` RNG
- 3-lane road logic
- Gas/brake, jump/hop, lane change
- Speed model, momentum multiplier (×1.0-×1.5)
- Collision boxes (AABB integer space)
- Delta-encoded input log `{tick, buttons-bitmask}`
- 3-Dent failure model (hit = 1 dent, -25% carried, 3 dents = run over)
- Separate skillCrowd vs displayCrowd

## Out of scope
- Rendering, graphics, sounds.
- Content loading (uses `SimConfig` passed in).

## Done when
- Unit tests prove same seed + same inputs = identical state over 10,000 steps.
- `pnpm verify` passes.
- No `Math.random` or floats used in state updates.
