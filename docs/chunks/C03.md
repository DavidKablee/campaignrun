# C03 — 3D Rendering (Three.js)
Status: in-progress      Depends on: C01, C02

## Goal
Render the deterministic 2D integer sim state as a low-poly 3D world.

## Scope
- `apps/game/src/render.ts`: Three.js WebGL2 renderer.
- Camera follows the player Z coordinate.
- Player character is drawn based on `activeContenderId`.
- Obstacles are drawn based on `entities`.
- Flat shaded, basic geometries for the low-poly style.
- `apps/game/src/main.ts` hooks up `requestAnimationFrame` to step the sim and render.

## Done when
- The player object moves across the screen.
- Obstacles spawn in the correct lanes and correspond to sim collisions.
- `pnpm verify` passes.
