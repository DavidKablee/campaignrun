## Shipped
- `packages/content/data/states/{oyo,borno,delta,kwara}.json`, matching `stateSchema` exactly (5 landmarks each, `venueType`, `hazards`, `welcomeLines`, `palette`, `biomeKit`, `signatureRide`, `audioStem`) — same shape as the existing `kano.json`/`lagos.json`. Every landmark is `verified: false`, per the spec's own "VERIFY with a local reviewer" guardrail — this is a researched starting point, not final/authoritative content.
- Landmarks researched via web search for real accuracy (Cocoa House/Bower's Tower/Agodi Gardens for Oyo; Monday Market/Borno Museum/El-Kanemi Stadium for Borno; Niger Bridge/Effurun Roundabout/Warri Township Stadium for Delta; Sobi Hill/Owu Falls/Kwara State Stadium for Kwara). `zone`/`audioStem` matched exactly to the pre-existing entries in `states-index.json` so there's no mismatch between the two.
- **Two real content-safety calls made during research, not just mechanical transcription:**
  1. Borno's obvious third anchor landmark (the Shehu of Borno's palace, named in the original spec notes) is a palace — `venueTypeSchema` already has no `palace` option at all (enforced at the schema level, confirmed by the existing "palaces cannot be venues" test), so it was replaced with Borno State Museum/El-Kanemi Stadium/Sanda Kyarimi Park/Ramat Polytechnic instead. Same for Kwara's Ilorin Emir's Palace, replaced with Kwara State Stadium/Oja Oba Market/Post Office Roundabout.
  2. Alau Dam (Borno) was deliberately **not** used despite being a well-known landmark: it catastrophically collapsed on 9 Sept 2024, flooding ~15% of Maiduguri. Using it as a flood-hazard flavour landmark in a satirical game would trivialize a real, recent disaster — against the game's own guardrail against referencing real incidents.
  3. No religious buildings (mosques, churches) used as landmarks — a satirical political rally mechanically happening "at" a mosque reads as disrespectful regardless of real-world accuracy.
- `signatureRide` values map to **existing** ride ids only (no dead references): Oyo/Borno → `okada` (explicit for Oyo per spec; Borno falls under the NE zone default), Delta/Kwara → `keke`. Delta's spec-intended signature (speedboat/canoe) isn't a ride that exists in the roster yet — `keke` is a placeholder substitute, documented here rather than silently wrong.
- New test in `packages/content/test/content.test.ts`: mirrors the existing "ships the 26 Oct week" check for this batch — loads each pack, confirms `audioStem` agrees with `states-index.json`, every `venueType` is schema-valid (so a palace can never sneak back in), and `signatureRide` always resolves to a real ride id.
