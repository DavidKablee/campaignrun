# C57 — Oyo's world

## Why
Same as C55; dossier `docs/research/states/oyo.md`.

## What
- **Landmarks** (`data/states/oyo.json`, all `verified: false`): Dugbe Market, Mokola Flyover, Agodi Gardens, Cocoa House, Asejire Reservoir. Palette sky `#A7C2D2`, fog `#E7DCC6`, ground `#98583C`, accent `#6F4A2E`; "Ẹ káàbọ̀ sí Ọ̀yọ́!" / "Ẹ ṣeun, Ọ̀yọ́!".
- **Route:** Dugbe → Mokola hill → Agodi → Dugbe/Onireke corridor → Osun valley road → Oyo road farm belt → Oke-Ogun hills → ridge above Ibadan. New library `data/world/forest-hills.json`.
- **Look:** `hill-asphalt` road, `earth-plaster` facade, `ibadan` shop boards, `yoruba-southwest` dress, `ibadan-roofsea` skyline (a hill of rust roof planes with one slim tower).
- **New styles:** lots `rust-bungalow`, `compound-row`, `afro-brazilian-storey`, `laterite-compound`; flora `forest-giant`, `cocoa`, `teak`; wall `cutbank`; kerbside `adireline`, `cocoasacks`, `okada`.
- **Set pieces** (`render/world/states/oyo.ts`): `oyo.dugbe-market`, `oyo.mokola-flyover`, `oyo.agodi-gardens`, `oyo.cocoa-house`, `oyo.asejire-reservoir`.

## Pitfall found
Legacy `scenery` strings in `world.ts` (for example "seven hills skyline", "cocoa warehouses") still generate large geometry and drew a brown slab across the screen. The Oyo pack uses unmatched strings. Check the `case` list in `world.ts` before writing `scenery` for a new state.
