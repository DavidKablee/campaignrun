# C84 — Mobilise lock, one way back, settings that work

## What changed
- Mobilise is locked below `places.followingGate` (1,000 Following, in `places.json`). The gate lives in `state.ts openPlaces`, so the splash, Briefing and invite links all obey it. The button says how far there is to go.
- The Convoy Yard and the result screen's small print are centred (scoped CSS; `.cr-fineprint { margin: 0 }` had beaten the column's auto margins).
- `nav.ts` is the one place that says where Back goes (`backTarget`, `goBack`). The on-screen arrows, Esc and the phone's Back now land on the same screen. `holdBackGuard` is a ref-counted history entry so hand-overs between menu, run and result do not pop it.
- Esc pauses a run and resumes it; on any menu it is Back. A sheet that wants Esc calls `preventDefault()` first.
- `prefs.ts`: Reduce motion and Data saver reach the stylesheet (`data-reduce-motion`, `data-data-saver` on `<html>`), haptics go through one `haptic()` helper, Mobilise respects all three.
