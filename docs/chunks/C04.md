# C04 — React UI Integration
Status: done      Depends on: C01, C02, C03

## Goal
Wrap the game inside a React shell and manage the UI flow (Splash -> Roster -> Game -> Summary).

## Scope
- `apps/game/src/App.tsx`: React component handling screen routing and UI overlay.
- Integrated `zustand` to drive screen transitions based on `screen` state.
- Splash screen with disclosure and play button.
- Roster screen to select a contender from `contenders.json`.
- Game screen which mounts the Three.js canvas and handles the keyboard inputs.
- Summary screen to show the run result.
- `apps/game/src/main.tsx` mounts the React tree.

## Done when
- Screens can be navigated through the UI.
- The game canvas properly mounts and unmounts without breaking.
- `pnpm verify` passes.
