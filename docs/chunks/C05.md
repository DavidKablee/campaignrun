# C05 — Pickups, Rides, and Perks
Status: in-progress      Depends on: C04

## Goal
Implement supporter pickups, ride upgrades, and contender perks inside the simulation.

## Scope
- `packages/sim/src/step.ts`: Spawning supporter groups (`[0.45, 0.85] * capacity`) and loose supporters.
- Collision with supporters adds to `carried`.
- Applying `activeContender` perk (e.g. magnet, double jump).
- Applying `activeRide` capacity and physics modifiers.
- `apps/game/src/App.tsx`: Roster needs to let you pick a ride if you have enough coins.

## Done when
- The sim correctly spawns and collects supporters.
- Run result uses actual collected supporters.
- `pnpm verify` passes.
