# C77 — The two sim decisions left open since C68

## What
- **Ride bonus removed:** `signatureRideBonusPermille` in `packages/content/data/sim.json` is now `1000` (no bonus), was `1100`. Why: GUARDRAILS forbids home-state bonuses, and `ADR-0010` says states differ in how they look and in hazard weights only. A +10% score for riding the ride a state is "known for" was a place-based gameplay edge that nothing on screen explained (no UI text, tutorial or ride card mentions it). The field stays in the schema and in `step.ts`, `replay.ts` and `plausibility.ts`, so every replay path still reads the same value and a future, openly stated mechanic can reuse it.
- **Replay safety:** there is no sim version number, so this change would invalidate any stored score made under 1100. The API is not deployed (STATUS, C37) and no leaderboard has been published, so nothing stored is affected. After a deploy this change would need a version bump.
- **Rivers ride:** `packages/content/data/states/rivers.json` `signatureRide` danfo → keke, and `state-roads.json` regenerated (`pnpm content:roads`). Why: the Rivers dossier sources describe keke, minibuses and shared cabs, with okada restricted in much of Port Harcourt; danfo is a Lagos word and bus. Keke now matches the Delta, Abia and Imo packs and the keke-swerve hazard. Counts of `signatureRide` across the 37 roads: keke 22.

## Not done
- Rides are still a free choice in every state; the signature ride is now a label for the state's look and radio flavour only. If you want a real, stated reason to pick a ride per state, that is a design change of its own.
- Only Lagos and Edo keep danfo (Edo was approved in Batch 5; Lagos is the original danfo city).
