# C02 — Client Local State & Audio
Status: in-progress      Depends on: C01

## Goal
Manage the player's non-sim progress, options, and sound.

## Scope
- `apps/game/src/state.ts`: Zustand store for local app state (screen routing, volume, selected contender, last run result, coin balance).
- `apps/game/src/audio.ts`: Audio manager that plays sfx in response to `SimEvent`s, and handles looping bgm.
- Local storage persistence for Zustand state (coins, selected contender).

## Done when
- State persists across reloads (coins, active contender, settings).
- `pnpm verify` passes.
