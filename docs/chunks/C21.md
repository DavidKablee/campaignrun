# C21 — Character rebuild: chibi + baked face + toon/outline
Status: done      Depends on: C20
## Goal
Replace the realistic ~7.2-head, 15+-overlapping-primitive character build (lumpy/uncanny on a real phone) with the ADR-0008 chibi direction: simplified ~4.3-head proportions, a single baked 2D face texture, and a real toon outline.
## Done when
All 6 contenders + outfit permutations render with no visible seams/lumps; per-character draw-call cost documented; `pnpm verify` green (sim/content untouched).
## Shipped
- `apps/game/src/render/character.ts` rewritten: new chibi skeleton constants (`HEAD_R`/`HIP_Y`/`THIGH`/`SHIN`/`TORSO_H`), far fewer/bigger body primitives, `faceTexture(look)` — a deterministic baked canvas (eyes/brows/nose/mouth/facial-hair), cached by look-signature, mapped onto a small flat plate with a soft radial alpha-feathered edge (not a hard rectangular sticker) so it blends into the curved cranium.
- `apps/game/src/render/materials.ts`: `outlineMat()` — a cheap backface-extrusion toon outline (shares geometry with the solid mesh, no extra buffers), 5-step toon gradient (was a flat 4-value ramp). Composes with the existing road-curve `patchBend`.
- Detail split: `'hi'` (player rig in `GameRenderer`, studio preview) gets the textured face plate + outline on every part mesh; `'lo'` (baked crowd via `personGeo`/`bakeCharacter`, always called with `'lo'`) stays a single merged vertex-coloured buffer with a simplified blank face — zero extra draw calls for crowds.
- `CharacterRig`/`buildCharacter`/`poseCharacter`/`disposeRig`/`bakeCharacter`/`randomPerson` signatures unchanged — `GameRenderer.ts`, `studio.ts`, `props.ts` needed no edits.
## Two real bugs found and fixed via the debug harness (keep in mind for C22/C23)
1. **Face plate z-depth**: a flat plate must clear the cranium sphere's surface at *every point it covers*, not just at its own center — otherwise the (opaque) sphere depth-occludes the middle of the face and only the plate's grazing edges show. Fixed by pushing the plate to `HEAD_R * 1.06` instead of `* 0.95`.
2. **Outline shader no-op**: `objectNormal` is only declared in MeshBasicMaterial's vertex shader when `USE_ENVMAP`/`USE_SKINNING` is defined, so referencing it silently fails to compile/link. The raw `normal` attribute is unconditionally declared by `WebGLProgram` for every material — use that instead for any custom vertex-shader patch that needs a normal and doesn't control the material's defines.
