# C50 — A world for every state (foundation) + Kano

## Why

Every state rendered the Lagos world: the same chunk seeds, the same theme order (Ojuelegba, two lagoon bridges, a market, then half the course as a park), the same shop signs, road, kerbs, bridges and people. A state differed by a colour tint and a billboard list, and `biomeKit` and each landmark's `venueType` were read by nothing. See ADR-0010 for the decision.

## What

- **Content.** `packages/content/src/world.ts`: `worldRefSchema` (the `world` block on a state), `districtSchema`, `roadStyleSchema`, `dressSetSchema`, `worldLibrarySchema`, `resolveWorld(state, library)` and `LAGOS_WORLD` (from `data/world-defaults.json`). `world-library.ts` lazy-loads `data/world/<name>.json` like a state pack. `guardrails.ts` also scans `data/world`.
- **Renderer.** `World` is district-driven: `districtAt(chunk)` replaces `themeAt`, `route[seg]` picks the district, the gantry fires on a district change, and `labelFor` uses landmark `min(seg, 4)`. Chunk RNG is `seed ^ salt` (salt 0 for Lagos) plus a second `rx` stream for regional builders. New `render/world/` modules: `ctx` (chunk context and texture keys), `regional` (side-op dispatch, bazaar, wall, kerbside), `lots` (building styles), `flora`, `pieces` (landmark set pieces), `skyline`, `venues` (rally-stage backdrops by venue type). `regionalTextures.ts` paints the sahel road, mud and block facades and the sahel shop set. `character.ts` gains NPC-only garments (`riga`, `isiagu`, `kube`, `hijab`, `turban`) and `dressedPerson`; `personGeo` takes a dress set. `buildVenue` takes the state's name instead of "LAGOS".
- **Wiring.** `useStateWorld(pack)` waits for the library; `RenderOpts` carries `world`, `stateName` and `venueTypes`; `legAt` takes the state's start label.
- **Fixed on the way.** Ground and water materials were keyed by theme, not colour, so the first state built in a session fixed the ground colour of every later one (the Lagos golden's `themed` capture was refreshed once for this). The initial fog colour was passed as a hex string without `#`. `flood-patch` and `narrow-gate` had no model and fell back to a sedan; they now have one.
- **Review aids** (need `?debug`): `debugState=<id>`, `debugWeather=day|night|harmattan|rainy`, `debugSeed=<n>`, `debugZ=<m>`.
- **Tests.** `worldGolden.test.ts` (Lagos fingerprint), `worldRegistry.test.ts` (every id the data names has a builder), `packages/content/test/world.test.ts`, and `apps/game/e2e/states.spec.ts` (screenshots and the draw/triangle budget per place on the course).
