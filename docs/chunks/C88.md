# C88 — UI/UX fix pass

From a platform audit (read of the code plus the running app). Layout, reach, size and focus only; no colours changed, the run HUD and pause card untouched.

## What changed
- **Splash on a short screen** (phone on its side, small window): it scrolls, the "On air" block steps aside and the 3D hero stays fixed behind. Mobilise, Board, Yard and About were unreachable at 844x390.
- **Mobilise landscape**: two columns, the stage on the left and the dock or tray on the right. The stage used to be 86 to 165 px tall once a tray was open.
- **Pinch-zoom** is allowed (`index.html` no longer sets `maximum-scale` or `user-scalable=no`).
- **Invite before the unlock**: a friend arriving with a `#mobilise=` link under 1,000 Following now sees "Kano Stadium is waiting for you. Reach 1,000 Following to join (N to go)" on the splash, and the invite is used when Mobilise opens (kept for the session only: `lockedInvite` in `state.ts`).
- **Mobilise gate**: while the account check is running it says "Checking your board name"; offline says "Opening soon" with Try again; only a signed-out player is asked to choose a name.
- **Back**: one round 44 px button on the Briefing, Roster, Board and Auth. Back from the Board returns to where it was opened (`previousScreen`, `nav.ts`) instead of always the Contender picker.
- **Disabled with a reason**: the result-screen Mobilise says how many Following to go; the sign-up button says what is missing.
- **Accessibility**: one `:focus-visible` outline in an existing colour, Mobilise action buttons are named by their visible text (it hid the cooldown before), emoji and language buttons are 44 px, nothing under 12 px, a People tray lists everyone in the room so mute and report no longer need a tap on a tiny avatar, focus moves into a tray and back.
- Roster lock wording no longer contradicts itself ("first full run locks it, then one switch").

## Tests
`apps/game/e2e/layout.spec.ts` (zoom allowed, splash reachable at 844x390, locked-invite banner, Back targets 44 px, sign-up hint, Mobilise landscape), `apps/game/test/nav.test.ts` (Board returns to its origin).

## Not done
- The Board's "A game board" line (C86) and the splash age line (required by guardrail 9) read as disclaimers outside About to the audit; left on purpose.
- The first `.cr-chip` definition is dead code and was not removed.
- Briefing in landscape still gives a third of the height to its sticky row.
- `places.spec.ts` could not run in the last pass: the dev API's daily guest limit (429) was used up by earlier test runs.
