# Environment asset credits

Background environment dressing (buildings, market props, foliage) in `apps/game/public/models/`
uses models from **Kenney** (www.kenney.nl), released under **CC0 1.0** (public domain —
no attribution legally required, credited here anyway per ADR-0009 and Kenney's own courtesy
request).

- **City Kit (Commercial) 2.1** — `kenney.nl/assets/city-kit-commercial` — low-detail buildings,
  awning/overhang/parasol market props.
- **Nature Kit 2.1** — `kenney.nl/assets/nature-kit` — palm trees, grass, stone path pieces.

License text: http://creativecommons.org/publicdomain/zero/1.0/

Characters, rides and all other gameplay-critical props are original and procedurally generated
in code (see ADR-0005, ADR-0007, ADR-0008) — nothing in this directory is used for those.
