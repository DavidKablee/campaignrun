# Shared UI primitives

No component library. Primitives are CSS classes in `apps/game/src/ui/styles.css`, used from `App.tsx`.

## Buttons
- `.cr-btn` — danfo primary, Archivo Black, 5px offset
- `.cr-btn--ghost` — outline
- `.cr-btn--hero` — splash primary (box-shadow pulse)
- `.cr-mini-btn` / `.cr-icon-btn` — compact chrome
- `.cr-link` — text back link

## Pills & chips
- `.cr-pill` / `.cr-pill--live`
- `.cr-chip` / `.cr-chip--trade`

## Cards & stats
- `.cr-card` — paper surface
- `.cr-stat` / `.cr-statrow` — HUD / splash metrics
- `.cr-kicker` — uppercase label

## Contender / portrait
- `.cr-contender`, `.cr-portrait`, `.cr-roster`

## Studio
- `.cr-studio`, `.cr-tabs`, `.cr-opt`, `.cr-swatch`

## Map
- `.cr-map-stats`, `.cr-state-grid`, `.cr-radio`

Full CSS: `apps/game/src/ui/styles.css`.
